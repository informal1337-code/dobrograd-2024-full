# Установка SteamCMD и Garry's ModDS (WINDOWS!)

## 1. Установка SteamCMD

### Скачивание SteamCMD
1. Перейдите на официальный сайт SteamCMD: https://developer.valvesoftware.com/wiki/SteamCMD
2. Скачайте архив `steamcmd.zip` для Windows
3. Распакуйте архив в удобную папку, например: `C:\steamcmd\`

### Первый запуск SteamCMD
1. Откройте распакованную папку
2. Запустите `steamcmd.exe`
3. Дождитесь завершения первоначальной установки
4. SteamCMD закроется автоматически после обновления

## 2. Установка GmodDS
### Установка
1. в консоли steamcmd пишете `login anonymous`
2. (ПО ЖЕЛАНИЮ) `force_install_dir C:\gmod_server` (либо другой путь, это по желанию)
3. `app_update 4020 validate`
4. `quit`

## 3. Первый запуск твоего сервера
### запуск
1. В папке `steamapps\common\GarrysModDS` создай файл `start.bat`
2. открываешь его, и вставляй туда:
```bat
@echo off
:srcds
echo (%time%) srcds started.
start /wait srcds.exe -console -game garrysmod +map rp_evocity_dbg_251031 +maxplayers 64 +port 27015 +gamemode darkrp +host_workshop_collection 570795184 -p2p
goto srcds
quit
```
3. теперь нажми на него два раза и у тебя начнет скачиваться контент (дело долгое) а после сам сервер запустится, в консоль выведется connect:p2p и его ты можешь дать друзьям что даст им подключится к твоему локальному серверу (не советую хостить под более 10 человек локальный сервер, тк p2p уязвимый а также очень легко положить сервер)

## Установка MySQL

1. Скачай последнюю версию **MariaDB** по [ссылке](https://mariadb.com/downloads/)
2. Запусти установщик.
3. Тебе предложат выбрать компоненты, которые нужно установить.  
   В рамках разработки достаточно будет конфигурации на скриншоте ниже.  
   Обрати внимание, что помимо сервера мы также устанавливаем **HeidiSQL** — это программа для взаимодействия с сервером, она нам понадобится в будущем.  
   ![MariaDB Components](https://i.imgur.com/yN64ieC.png)
4. На следующем шаге тебе предложат указать пароль от главного аккаунта сервера (имеет полный доступ).  
   В рамках работы с локальной базой данных **рекомендуется этого не делать**.  
   Сервер будет использоваться только тобой, и если ты не будешь указывать пароль, не придётся ничего настраивать дополнительно.  
   ❗ **Не забудь также поставить галочку напротив «Use UTF8 as default server’s character set»**:  
   ![UTF8 Setting](https://i.imgur.com/0GJAk0P.png)
5. На следующем шаге чаще всего менять ничего не нужно:  
   ![Default Config](https://i.imgur.com/DbUFw2v.png)
6. Наконец, дождись окончания установки. После этого установщик можно закрыть.

## Подключение к БД

После установки сервера у тебя должен был установиться **HeidiSQL** — интерфейс для взаимодействия с базами данных.  
Если этого не произошло, скачай и установи её по [ссылке](https://www.heidisql.com/download.php)  
![HeidiSQL Interface](https://i.imgur.com/WQDksXC.png)

Запусти её.

В открытой программе нажми **«New»**:  
![New Session](https://i.imgur.com/hLweTHK.png)

В разделе **«Settings»** укажи следующие параметры:

| Параметр           | Значение         |
|--------------------|------------------|
| Network type       | MariaDB or MySQL (TCP/IP) |
| Hostname / IP      | `127.0.0.1`      |
| User               | `root`           |
| Password           | *(ничего)*       |
| Port               | `3306`           |

![Connection Settings](https://i.imgur.com/X4CGfeK.png)

Затем **сохрани** (`Save`) и выполни вход (`Open`).

> 💡 Если хочешь, можешь удалить базу данных `test`. Для этого нажми правой кнопкой мыши по ней в списке и выбери **«Drop»**.

Все таблицы должны содержаться в конкретной базе данных.

Далее **создаёшь новую БД**:  
![Create DB](https://i.imgur.com/jIBYdyO.png)  
и называешь её **`dbg`** (никак иначе).

## Если ты на хостинге

Буду показывать пример на своём хостинге:

1. Заходишь на хостинге во вкладку **Databases** (или что-то подобное).
2. Нажимаешь на **New database**, после чего появится меню **"Create new database"**.  
   Там указываешь:
   - **Database Name**: `dbg`
   - **Connections From**: оставляешь пустоту.
3. Нажимаешь **Create new database**.
4. Теперь тебе нужно получить и записать все данные БД (пароль, имя и т.д.) и зайти в файл:  
   `_config/lua/config/octolib_sv.lua`

Там будет:

```lua
CFG.db = {
	host = 'localhost',
	user = 'root',
	pass = '',
	port = '3306',

	main = 'dbg',
	admin = 'dbg',
	shop = 'dbg',
}
```
Заполняешь так:
```lua
CFG.db = {
	host = 'хост, --пример db.worldhosts.fun',
	user = 'юзер, --примерно так выглядит он везде: u17670_J7m4qk',
	pass = 'пароль, --ну тут понятно',
	port = '3306', -- оставляем.

	main = 'dbg', -- меняем на тот нейм который выдал нам хост, пример: s17675_dbg
	admin = 'dbg', -- меняем на тот нейм который выдал нам хост, пример: s17675_dbg
	shop = 'dbg', -- меняем на тот нейм который выдал нам хост, пример: s17675_dbg
}
```
✅ Всё, если ты увидел в консоли Database connected — у тебя всё получилось!

## Смена персонажей:

## Тюрьма:
Зайди в `addons\_config\lua\config\groups\prison.lua` и там на строке ~106 будет spawns[] эти значения изменяешь.
## А как-же менять позиции, как копировать и так далее?
Смотри, тебе нужно в игре на определенной карте встать на ту позицию которую ты скопируешь, и в консоль ввести команду inf_copypos у тебя скопируется код, его вставляешь туда куда надо, все просто :)
